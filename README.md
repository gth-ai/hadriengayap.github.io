# Hadrien Gayap - Professional Portfolio

A modern, responsive single-page portfolio website showcasing my research in Artificial Intelligence, Bioinformatics, and leadership in community engagement.

## 🎯 About

This portfolio highlights:
- **Research & Publications**: 26 publications including journal articles, conference papers, and workshops
- **Professional Experience**: Work in AI, bioinformatics, and cancer detection
- **Leadership**: Community engagement and volunteer work
- **Awards & Recognition**: Over $28,750 in scholarships and awards

## 🚀 Features

- **Modern Design**: Clean, professional single-page layout with smooth scrolling navigation
- **Interactive Elements**: 
  - Real-time publication filtering (by type, year, status)
  - Search functionality for publications
  - Animated statistics counters
  - Scroll-reveal animations
- **Responsive**: Fully responsive design optimized for mobile, tablet, and desktop
- **Performance**: Zero external dependencies, optimized loading with vanilla JavaScript
- **Accessibility**: Semantic HTML, ARIA labels, and keyboard navigation support

## 🛠️ Technologies

- **HTML5**: Semantic structure
- **CSS3**: Modern styling with CSS Grid, Flexbox, and animations
- **Vanilla JavaScript**: Interactive features without external dependencies
- **No Build Process**: Simple deployment to GitHub Pages

## 🎨 Design Features

- **Color Scheme**: Professional blues and greens for a scientific/tech aesthetic
- **Typography**: System fonts for optimal performance and readability
- **Animations**: Smooth scroll-triggered animations using Intersection Observer API
- **Navigation**: Sticky header with active link indication
- **Cards**: Hover effects and transitions for better user engagement

## 📊 Sections

1. **Hero**: Introduction with photo, tagline, and call-to-action
2. **About**: Professional profile, skills, and education timeline
3. **Research & Publications**: Interactive filterable publication list (26 items)
4. **Professional Experience**: Timeline of work positions
5. **Leadership & Community**: Volunteer and leadership roles
6. **Awards & Recognition**: Scholarships, awards, and affiliations
7. **Contact**: Contact information and message form

## 🚀 Deployment

This site is designed to be deployed on GitHub Pages:

1. Push the repository to GitHub
2. Go to repository Settings → Pages
3. Select the main branch as source
4. Your site will be live at: `https://hadriengayap.github.io/`

## 📱 Responsive Breakpoints

- **Tablet**: 768px - 1024px
- **Mobile**: < 768px
